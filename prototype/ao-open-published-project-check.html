Notes & open questions for stakeholders
Answered Is “my AI Agents projects” data already available on this page?
Yes. fetchCognigyProjects() (the actual service name in the codebase) already backs the Project Name dropdown. Reuse that list — no new fetch.
Answered Is access checked per version or per agent?
Per version. Each PublishedMetadata carries its own projectId; an agent can be published across several projects, so the dropdown gates row-by-row.
Answered What disabled-button treatment should we use?
Reuse the existing pattern — the <span>-wrapped disabled button + tooltip already used for the empty-projects case in view-ai-agent-header.tsx. Don’t invent a new one.
Open Do we track “Published By” separately from “Created By”?
Which is authoritative if they diverge? Access is really a project-membership question, so likely neither — but confirm the data model before build.
